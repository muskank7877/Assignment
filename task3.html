Assignment 3: Terminal Navigation Practice

Objective

To learn basic terminal commands and navigate between directories.

Commands and Their Uses

  1. cd - Displays the current directory.
  2. dir - Lists files and folders.
  3. D: - Switches to the D drive.
  4. mkdir TerminalPractice - Creates a new folder.
  5. cd TerminalPractice - Enters the practice folder.
  6. cd .. - Moves to the parent directory.
  7. cls - Clears the terminal screen.
  8. exit - Closes Command Prompt.

Procedure

I opened Command Prompt and practised the commands listed above to navigate between directories and view folders.

Result

I successfully practised basic terminal navigation commands.

Conclusion

Terminal commands help users navigate directories and view files and folders.
