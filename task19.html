HTML Meta Tags Audit

Purpose of Meta Tags

Meta tags provide information about an HTML document. They are placed inside the head section of an HTML page.

Meta Tags Used

  • Charset: Defines the character encoding as UTF-8.
  • Viewport: Helps the page display properly on different devices.
  • Description: Provides a short description of the page.
  • Author: Identifies the author of the page.

Audit Result

Important meta tags have been added to the head section.
